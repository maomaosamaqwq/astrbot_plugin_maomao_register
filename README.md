# 猫猫AI网站注册插件

为 AstrBot 的 LLM 提供注册猫猫AI网站（🥜.🐱）账号的工具。

## 功能

用户只需要对 bot 说类似的话：
- "帮我注册一个账号"
- "我要注册"
- "注册"

LLM 会自动调用本插件的工具，用用户的**QQ邮箱**作为用户名完成注册。

## 原理

- 插件通过 `@filter.llm_tool` 注册了一个 `register_website_account` 工具
- LLM 在对话中会自动判断用户意图，调用此工具
- 工具会获取用户的 QQ 号，构造 `{QQ号}@qq.com` 作为用户名
- 调用网站后端 API `api.仙狐大人.我爱你/register` 完成注册
